## 6. Ошибка CSP в консоли
- **Источник:** у самого сайта встроенных скриптов нет, это проверено со строгой CSP. Ошибку давали служебные страницы Firebase /__/auth/action, которые открываются по ссылке из письма (подтверждение почты, сброс пароля). Они используют встроенные скрипты, а наш заголовок CSP их блокировал.
- **Сделано:** строгая CSP (`script-src 'self'`, без `unsafe-inline`) по-прежнему действует на все страницы сайта, кроме служебных путей Firebase /__/.
- **Проверено:**
  - тест src/csp.test.js;
  - выкладка с новым правилом прошла успешно.

  - в «Моих курсах»;
