# Polygloto v2: бэклог

Согласованные на будущее фичи. Сейчас не реализуются, это список, чтобы
ничего не забыть, когда дойдёт очередь до второй версии. Ограничения v1
остаются в силе: бесплатный тариф Spark, без Cloud Functions и Storage
(см. [security.md](security.md) и [data-model.md](data-model.md)).

## Приоритет №1

- **Интервальные повторения слов (SRS).** Карточки из словаря курса,
  расписание повторений по ответам учащегося, «слова на сегодня».

## Контент и авторам

- Аудио-вставки (блок `audio` уже зарезервирован в формате контента).
- Подстрочный грамматический разбор, interlinear gloss (зарезервирован блок `gloss`).
- Шаблоны уроков.
- Статистика по ошибкам в заданиях.
- Импорт и экспорт курса.

## Новые типы заданий

- Собрать предложение из слов.
- Аудирование.
- Выбор нескольких правильных ответов.

## Геймификация

- Стрики (дни подряд).
- Ежедневные задачи.
- Мини-игры на слова.
- Общий и еженедельный рейтинг.
- Больше бейджей.

## Сообщество

- Подписки на авторов.
- Совместное создание курса.
- Комментарии на уровне отдельных уроков.
